===================

  • Estado de ocupación simulado

  • Usuario selecciona EXACTAMENTE qué asientos quiere
  • Mapa interactivo en página de compra
  • Estado ocupado = realmente comprados (JSON)
  • Validación robusta server-side

🔐 OCUPACIÓN REAL DESDE JSON

Antes de Compra:
  • Lee compras.json
  • Extrae asientos de cada compra
  • Solo esos están ocupados (rojo)

Compra 1: A1, A2
Compra 2: A1 (evento 4)
Compra 3: B1

Resultado:
  Evento 1: A1, A2, B1 ROJOS
  Evento 4: A1 ROJO
  Resto: VERDES


✅ VALIDACIONES ROBUSTAS

1. ✅ Nombre no vacío
2. ✅ Correo no vacío  
3. ✅ Al menos 1 asiento
4. ✅ Asientos no ocupados
5. ✅ Cantidad disponible

Error específico para cada caso:
  "El asiento A1 ya está ocupado"
  "Por favor selecciona al menos un asiento"
  "No hay suficientes entradas disponibles"

Complejidad:
  • obtener_asientos_ocupados: O(n compras)

Escalabilidad:
  ✅ Funciona con miles de eventos
  ✅ Funciona con miles de compras
  ✅ Respuesta rápida (< 100ms)


🔄 FLUJO DE USUARIO COMPLETO
=============================

1. Usuario abre http://localhost:5000/
   ├─ Ve 4 eventos
   └─ Haz clic en Festival de Música

2. Detalle de evento
   ├─ Ver información
   ├─ Entradas disponibles: 495
   └─ Haz clic "Comprar Entrada"

3. Página de compra (NUEVA)
   ├─ Mapa interactivo visible
   ├─ A1, A2, B1 en rojo (ocupados)
   ├─ Resto en verde (disponibles)
   ├─ Haz clic en A3, A4, A5 (3 asientos)
   └─ Se resaltan en azul

4. Completa datos
   ├─ Nombre: "Juan Pérez"
   ├─ Correo: "juan@example.com"
   └─ Total: $135.00 (3 × $45)

5. Haz clic "Comprar Ahora"
   ├─ Backend valida:
   │  ├─ Nombre ✓
   │  ├─ Correo ✓
   │  ├─ Asientos: A3, A4, A5 no ocupados ✓
   │  └─ Cantidad: 3 < 495 ✓
   ├─ Guarda compra con asientos: ["A3", "A4", "A5"]
   └─ Actualiza entradas: 495 - 3 = 492

6. Confirmación
   ├─ Título: "¡Compra Exitosa!"
   ├─ Asientos: A3, A4, A5 en badges
   ├─ Botón "📥 Descargar Entrada PDF"
   └─ Botón "📋 Ver Historial"

7. Historial
   ├─ Ver todas las compras
   ├─ Muestra asientos reales
   └─ Botón descargar PDF individual

8. Nuevo intento: Comprar A3 nuevamente
   ├─ Página de compra
   ├─ A3 ahora en rojo (ocupado)
   ├─ Usuario selecciona A6
   ├─ Compra exitosa
   └─ A3, A4, A5 permanecen ocupados


VALIDACIONES EN ACCIÓN
=======================

Caso 1: Intenta comprar sin nombre
  Error: "Por favor completa nombre y correo"
  ✓ No se guarda compra

Caso 2: Intenta comprar A1 (ocupado)
  Error: "El asiento A1 ya está ocupado"
  ✓ No se guarda compra

Caso 3: No selecciona asientos
  Error: "Por favor selecciona al menos un asiento"
  ✓ No se guarda compra

Caso 4: Selecciona A3, A4, A5 correctamente
  ✓ Compra se guarda
  ✓ Asientos en JSON: ["A3", "A4", "A5"]
  ✓ Entradas disponibles se actualizan
