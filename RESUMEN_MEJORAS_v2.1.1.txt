MEJORA 1: MOSTRAR NÚMERO DEL ASIENTO
────────────────────────────────────

✨ ANTES:
  Botones vacíos
  Usuario tenía que pasar mouse (hover) para saber el número
  
✨ AHORA:
  Cada asiento muestra su número directamente
  Ejemplo: [A1] [A2] [A3] ... [J15]
  Números visibles sin necesidad de hover
  Tamaño aumentado para legibilidad (30px → 35px)
  
  Implementación:
  ├─ Agregado: <span class="numero-asiento">{{ codigo }}</span>
  ├─ CSS nuevo: .numero-asiento
  └─ Fuente más grande y osada


MEJORA 2: DESELECCIONAR ASIENTOS
────────────────────────────────

✨ ANTES:
  Click en asiento lo seleccionaba (permanente)
  No había forma de deseleccionar sin empezar de nuevo
  Frustración al cometer errores

✨ AHORA:
  Click en asiento seleccionado → Se deselecciona automáticamente
  Color vuelve a VERDE inmediatamente
  Se elimina del resumen al instante
  Total se recalcula automáticamente
  
  Implementación:
  ├─ Actualizado: JavaScript toggleAsiento()
  ├─ Ahora agrega clase "disponible" al deseleccionar
  └─ Feedback visual inmediato


FLUJO DE USO
───────────

1️⃣  Usuario abre mapa de asientos
   └─ Ve números en todos los asientos

2️⃣  Usuario selecciona A3, A4, A5
   └─ Se resaltan en AZUL
   └─ Resumen: [A3][A4][A5]
   └─ Total: $135.00

3️⃣  Usuario se arrepiente de A4
   └─ Hace clic en A4
   └─ A4 vuelve a VERDE
   └─ Se elimina del resumen
   └─ Resumen: [A3][A5]
   └─ Total: $90.00

4️⃣  Usuario completa datos y compra
   └─ Backend recibe exactamente: A3, A5
