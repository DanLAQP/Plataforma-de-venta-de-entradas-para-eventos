⭐ NUEVAS CARACTERÍSTICAS (v2.0)

  🎟️  CÓDIGOS QR
      • Se generan automáticamente en cada compra
      • Formato único: ENTRADA-{id}-{evento_id}
      • Incluidos en PDFs descargables

  🗺️  MAPA DE ASIENTOS INTERACTIVO
      • Visualización de 150 asientos (10x15)
      • Verde = Disponible, Rojo = Ocupado
      • Estadísticas de ocupación en tiempo real
      • Asignación automática al comprar

  📥 DESCARGAR ENTRADAS EN PDF
      • Documento profesional y atractivo
      • Incluye: evento, comprador, asientos, código QR
      • Descargable desde confirmación e historial
      • Formato: entrada_[NombreEvento].pdf

  📊 API REST MEJORADA
      • Nuevo endpoint: /api/asientos/<evento_id>
      • Obtén datos en JSON para integración externa
      • Perfecto para aplicaciones móviles

📦 INSTALACIÓN RÁPIDA

  1. Instalar dependencias:
     
     pip install -r requirements.txt
     
     O usar el script automático:
     
     python install.py

  2. Ejecutar la aplicación:
     
     python app.py
     
     O en Windows (doble clic):
     
     run.bat

  3. Abrir en navegador:
     
     http://localhost:5000/

🎯 PRUEBA LA APLICACIÓN

  Recomendamos seguir este flujo:

  1️⃣  Ve a la página principal
      • Ver listado de eventos disponibles

  2️⃣  Haz clic en un evento
      • Mira los detalles y descripción

  3️⃣  Haz clic en "Ver Mapa de Asientos"
      • Visualiza la grilla interactiva
      • Observa asientos disponibles (verdes)

  4️⃣  Regresa y haz clic en "Comprar Entrada"
      • Completa nombre, correo, cantidad
      • Compra será procesada

  5️⃣  En la confirmación
      • Verás tus asientos asignados
      • Descarga tu entrada en PDF

  6️⃣  Ve al "Historial"
      • Mira todas tus compras
      • Descarga PDFs cuando quieras

  GET  /                              - Página principal
  GET  /evento/<id>                   - Detalle del evento

💡 TIPS Y TRUCOS

  • Los códigos QR se generan automáticamente
  • Los asientos se asignan aleatoriamente en orden
  • Los PDFs se pueden descargar múltiples veces
  • Los datos se guardan en archivos JSON
  • Limpia archivos temporales con: python cleanup.py
  • Verifica la instalación con: python verify.py

🆘 SOLUCIÓN DE PROBLEMAS

  "No module named 'qrcode'"
  → pip install -r requirements.txt

  "Port 5000 already in use"
  → Cambia el puerto en app.py

  "Template not found"
  → Verifica que la carpeta app/templates/ exista

  Los PDFs no se descargan
  → Verifica permisos en la carpeta app/

  El mapa de asientos no se ve
  → Limpia caché: Ctrl+Shift+Delete
